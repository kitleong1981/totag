Site Credentials

FTP/SFTP login for each stock site. Leave a site's fields blank to skip it — uploads and CSV generation silently skip any site without credentials. Passwords are never sent back to the browser; leave the password field blank on an already-configured site to keep it unchanged.

AI Endpoint (required to use AI generation)

Any OpenAI-compatible vision endpoint — OpenAI itself, or a self-hosted/compatible server. The key is never sent back to the browser; leave it blank to keep the one already saved.

Google Maps API Key (optional — GPS location keywords)

Used for reverse-geocoding and nearby-landmark keywords. Leave unset and park/landmark containment keywords (OSM Overpass) still work with no key at all. The key is never sent back to the browser; leave blank to keep the one already saved.
